Вопросы и ответы

Часто задаваемые вопросы

Как начать играть с ZzidulyaDLC? +
1. Зарегистрируйтесь на сайте.
2. Приобретите или получите ключ доступа у владельца.
3. Активируйте ключ в личном кабинете.
4. Скачайте официальный лоудер `ZzidulyaLoader.exe`, введите ваш ключ — он сам скачает файлы и запустит игру без лишних батников.
Какая версия Java требуется? +
Клиент поставляется в комплекте со встроенной автономной Java (JRE). Вам не нужно ничего дополнительно устанавливать — всё настроено и запускается в один клик.
Банят ли за клиент на серверах? +
Клиент оптимизирован для максимальной скрытности. Все ротации и дистанции соответствуют легитным лимитам при правильной настройке конфига.
